# FreelanceGuard — AI Safety Copilot for Freelancers

FreelanceGuard analyzes freelance job posts and client messages for potential risk signals, explains the evidence, and helps freelancers respond safely.

## Features
- Risk assessment (LOW / MEDIUM / HIGH)
- Red-flag detection with evidence quotes
- Explanation of findings
- Recommended action
- AI-generated safe response

## Tech Stack
Streamlit · Groq · Pydantic · JSON knowledge base
